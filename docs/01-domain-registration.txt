# 🌐 Prepare Custom Domain

---

# 📖 Overview

In this milestone, an existing custom domain was prepared for use in the project.

Instead of registering a new domain through Amazon Route 53, a domain that was previously purchased from **Hostinger** was selected. This domain will be integrated with Amazon Route 53 in the upcoming milestones to enable DNS management and routing to AWS services.

---

# 🎯 Objective

The objective of this milestone was to:

- Use an existing custom domain
- Verify the domain ownership and active status
- Confirm the domain is ready for AWS Route 53 integration
- Prepare the domain for DNS management and routing

---

# 🌍 Domain Information

| Property | Value |
|----------|-------|
| Domain Name | dhruvmishra.co.in |
| Registrar | Hostinger |
| Domain Status | Active |
| Auto-Renewal | Disabled |
| Expiration Date | 12 June 2027 |
| Current Nameservers | apollo.dns-parking.com<br>athena.dns-parking.com |

---

# 🏗️ Implementation Steps

## Step 1

Purchased and registered the custom domain **dhruvmishra.co.in** through **Hostinger**.

---

## Step 2

Opened the **Hostinger Domain Dashboard** to verify the domain details.

---

## Step 3

Verified the following information:

- Domain is active
- Ownership information is configured
- Expiration date is valid
- Current nameservers are assigned

---

## Step 4

Confirmed that the domain is ready to be connected with **Amazon Route 53** in the next milestone for DNS management.

---

# ✅ Result

The custom domain **dhruvmishra.co.in** is active and ready for integration with Amazon Route 53.

This domain will be used throughout the project to demonstrate DNS routing to Amazon S3 Static Website Hosting and Amazon EC2.
